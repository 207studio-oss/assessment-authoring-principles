# 출제 원리와 문항 검토

사용자가 정한 학습 범위 안에서, 학생이 제공된 근거로 풀 수 있고 교사가 일관되게 채점할 수 있는 평가를 만든다. 요구 사고, 난도, 인지 부하는 서로 구분한다.

교사가 제공한 학습 범위·원자료·견본을 확인한다. 원문에 없는 정답·학교 정보·수업 내용을 추정해 채우지 않는다. 기존 문항을 수정할 때는 요청 범위와 미수정 자료를 보존한다.

## 출제에서 완료까지

1. 문항별 `목표 → 학생에게 주는 근거 → 필요한 판단 → 정답 → 채점 증거`를 연결한다. 정의를 형식만 바꿔 반복하거나 다른 문항에서 답을 알려 주는지 본다.
2. 발문·자료·정답·해설·채점 기준을 함께 설계한다. ‘모두’는 전체 정답 집합, ‘한 종류’는 하나의 타당한 예다. 그림은 상황을 구체화하되 판단을 대신하지 않게 한다.
3. 정답을 숨기고 다시 풀어 다른 해석·반례·타당한 대안을 찾는다. 한 문항의 설명이나 선지가 다른 문항의 답을 알려 주는지도 본다.
4. 발문 변경이 자료·답안·해설·부분점수·응답 유형·답란에 모두 반영됐는지 대조한다. 전체 검수에서는 목표 중복, 순서, 총 문항 수와 배점도 확인한다.
5. 실제 학생용 출력에서 그림·기호·답란·쪽 경계·정답 누출을 확인한다. 출력하지 못했으면 문서 검토와 실제 인쇄 검수를 구분해 보고한다.
6. 실제로 확인한 범위와 남은 한계를 보고한다. 학생 응답·시간·부하를 측정하지 않았다면 측정값처럼 쓰지 않는다.

## 먹이 관계 보조 도구

```text
python scripts/foodweb.py references/synthetic-foodweb.json --remove plant-a
```

보조 도구는 합성 그래프의 직접 먹이 상실과 남은 생산자 경로만 계산하며 실제 생존·개체 수를 예측하지 않는다. 실제 시험 자료·학생 기록은 공개 예제로 사용하지 않는다.
