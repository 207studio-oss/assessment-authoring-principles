# 과목별 범위

교사가 지정한 학습 범위·수업 자료와 현행 교육과정을 확인한다. 과목·학년·교과서의 범위를 자동 추정하지 않는다.

## 견본 문체

제공된 견본의 ‘보세요/인가요’ 또는 ‘하시오/입니까’ 문체를 따른다. 과목만 보고 특정 문체를 강제하지 않는다. 국어 인용문·인물의 어투는 보존한다. 무관한 문항까지 일괄 치환하지 않는다. 견본에 없는 [안내]·[정답] 상자나 난도 배지를 덧붙이지 않는다. 학교·로고·쪽수를 추정해 채우지 않고 기존 빈칸과 답란을 존중한다.

## 과학

정의·명칭뿐 아니라 관찰·비교·통제·해석·예측·근거 설명을 목표에 맞게 배합한다. 고정 비율은 없다. 관찰 시간·방법·단위를 명시하고 관찰된 수를 실제 전체 개체 수와 동일시하지 않는다. 참인 오답 선지가 다른 서술형의 답을 미리 알려 주는 경우도 점검한다.

### 생물과 환경

교사가 명시한 범위에서 생태계 요소·상호작용, 생물의 역할, 먹이 관계, 인간 활동과 보전을 다룬다. 화살표 방향과 직접·간접 관계를 구분한다. 생산자 소실 때 직접 먹이를 모두 잃는 집합, 간접 영향, 다른 생산자에서 이어지는 경로를 혼동하지 않는다. 가능한 변화를 설명하되 생존·수의 변화량을 보장하지 않는다. 관리 대안은 원인과 생물의 먹이·서식 조건을 연결하게 한다.

## 초등 4학년 수학

명시된 과목·학년·단원으로 범위를 정한다. 학년군 성취기준의 숫자나 단원 번호로 학기·교과서 배당을 추정하지 않는다. knowing/applying/reasoning은 사고 종류이며 정답률 난도·인지 부하와 같지 않다.

### 삼각형

실제 수업 범위를 확인하고 변 기준·각 기준의 분류를 구분한다. 정삼각형이 이등변삼각형에 포함되는 관계, 예각삼각형의 세 각 모두가 예각이라는 조건을 반영한다. 여러 기준의 이름을 함께 물으면 정답 집합을 명시한다.

밑각·정삼각형의 각·내각합·측정은 실제 수업 범위에서 다룬다. 외각 정리 암기, 합동 증명, 높이·넓이, 닮음, 피타고라스 정리를 기본 분류 단원에 자동 추가하지 않는다. 실제 각·길이·그림 표시의 일치를 검증하고 그림 방향으로 답을 유도하지 않는다.
