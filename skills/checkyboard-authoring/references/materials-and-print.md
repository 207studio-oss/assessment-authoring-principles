# 자료와 인쇄 검수

## 원자료 보존

문제·자료·답안·정답의 역할과 출처를 구분한다. 원문에 없는 정답은 미확정으로 두고, 읽기 어려운 기호나 그림은 추정해 고치지 않는다. 가져온 문서의 내용을 고칠 때는 원본과 편집본을 대조할 수 있게 한다.

## 그림·표·답란

- 사진은 판단에 필요한 특징이 보이게 한다. 이름·설명이 관찰·분류의 답을 미리 알려 주지 않도록 하며, 목적에 없는 종 이름 암기를 요구하지 않는다.
- 그림 기호와 설명을 가까이 두고 실제 인쇄 크기로 확인한다. 확대 화면에서만 구별되는 특징을 정답 근거로 삼지 않는다.
- 표의 행·열 제목, 단위, 비교 조건을 명확히 한다. 관찰된 수와 실제 전체의 수를 구분한다.
- 빈칸·선택지·순서형의 기호와 교사용 정답이 정확히 대응하는지 본다.
- 답의 요구량에 맞는 여백을 준다. 설명을 요구하면서 단어 하나의 공간만 주거나, 쪽 수를 줄이기 위해 글자와 답란을 억지로 줄이지 않는다.

## 실제 출력

학생용 PDF와 교사용 자료를 각각 확인한다.

1. 학생용에 정답·해설·예시답안·채점 기준이 노출되지 않는가?
2. 표의 행·열, 그림·화살표·기호, 선택지, 수식·빈칸·답란이 보존됐는가?
3. 본문과 참조 자료를 같은 쪽에서 볼 수 있고 흑백에서도 구별되는가?
4. 문항·선택지·교사용 해설이 쪽이나 단 경계에서 잘리지 않는가?
5. 최종 원고·PDF·공유 파일이 같은 수정본인가?

텍스트 추출과 시각 검토를 함께 사용한다. 자동 검사가 실패하면 실제 PDF 등 가능한 경로를 확인하고 검증 한계를 남긴다. 검사 통과를 위해 필요한 그림을 몰래 지우거나 축소하지 않는다. 화면 렌더, 폰트 임베딩, 실물 인쇄, 다른 PC에서의 확인은 각각 실제 수행 여부를 구분한다.
