# 출제 원리와 전체 검수

문항 하나는 하나의 중심 목표를 갖는다. 같은 현상의 위험과 대안을 비교할 수는 있지만 관련 없는 안전·예절·계산·명칭 암기를 덧붙여 복잡하게 만들지 않는다. 문장 길이나 요구 수 자체를 심화로 부르지 않는다.

## 상황과 근거

- 공간·대상·변화 전후·비교 조건을 학생이 확인할 수 있게 한다. 숨은 생활 경험이나 머릿속 장면 구성을 교과 지식 대신 평가하지 않는다.
- 사진·그림·표가 판단 근거인지 장식인지 구분한다. 자료를 지워도 같은 답을 고르면 발문이나 자료의 역할을 재검토한다.
- 기호와 묶음의 범위를 중립적으로 표시한다. 그림이 장면을 제공하는 것과 정답 추론을 대신하는 것은 다르다.
- 모형의 가정, 화살표 방향, 시간·방법·단위를 필요한 만큼 밝힌다. 관찰 사실·가능한 추론·추가 확인이 필요한 결론을 구분한다.
- 가상 기록은 가상임을 표시하고, 모형의 결과를 현실의 모든 상황에 일반화하지 않는다.

## 문항과 정답

‘모두’는 정답 전체 집합을 먼저 열거한다. 발문을 바꾸면 정답·해설·부분점수·응답 유형·답칸을 함께 바꾼다. 선택형 오답은 가능한 오개념이나 자료 읽기 오류를 반영하고, 정답만 길거나 오답이 모두 터무니없는 단서를 점검한다. 기초 문항을 무조건 어렵게 만드는 것은 검수의 목적이 아니다.

서술형은 다른 타당한 방법과 표현을 인정한다. 설명을 요구하면서 단어 하나만 적을 수 있는 답란을 주지 않는다. 채점자가 각 요소와 부분점수를 구분할 수 있게 기준을 쓴다.

## 검수 관문

| 관문 | 확인할 것 |
|---|---|
| 범위 | 과목·학년·수업 자료·성취 목표의 실제 근거 |
| 내용 | 사실·용어·계산·인과 관계·모형 가정 |
| 풀이 | 학생용 지면에서 정답을 숨긴 첫 풀이, 문항별 찾을 정보·할 판단·남길 답, 다른 정답과 반례 |
| 자료 | 그림·표·화살표·기호와 발문의 대응 |
| 인지 부하 | 무관한 조건 유지, 자료 왕복, 과제 누적, 읽기 부담 |
| 채점 | 요구 요소·예시답안·허용 대답·부분점수 |
| 시험 전체 | 번호순 풀이에서 자료 읽기·답 쓰기 방식의 전환과 부담이 쌓이는 구간, 목표 중복, 답 단서, 문항 수·배점·시간 |
| 출력 | 실제 PDF의 정보 보존, 정답 누출, 글자·답란·쪽 나눔 |
| 전달 | 최종 원고와 출력본의 일치, 검증 범위 |

자동 검사·교사 판단·실제 학생 측정을 구분한다. 실제 시행 전의 난도·소요 시간·부하는 설계상 예상으로 남긴다. 정책을 읽었다는 사실이 검증 통과를 뜻하지 않는다.
